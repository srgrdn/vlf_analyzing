# Грозопеленгационная сеть: заметки

Всё делается для построения грозопеленгационной сети. Одна из задач — распознавание радиоимпульсов.

## Что нужно сделать

- Записывать количество сфериков в файле (в минутной записи).
- Формировать результирующую таблицу:
  - сначала для каждого файла отдельно;
  - затем сводку по количеству в файле;
  - поля: время (из имени файла), уровень сигнала, канал;
  - использовать для статистики (гистограмма).
- Удалять пустые записи.
- Анализировать сразу по двум каналам, чтобы сравнить, откуда больше сфериков.
- Использовать 2 директории: `processing1` и `processing2` — для сфериков и для вистлеров.

## Почему не пороговый детектор

Бывают локальные помехи высокого уровня (на 25 кГц и 40 кГц), поэтому нейросеть подходит лучше.
